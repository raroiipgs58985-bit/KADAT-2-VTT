# Копии канонических таблиц KADAT

Копии трёх канонических таблиц ([rules-sources.md](../docs/rules-sources.md)) **без
картинок**: все листы, значения ячеек, формулы, таблицы и комментарии сохранены, вырезаны
только изображения (из-за них оригиналы весят 27–62 МБ).

Оригиналы — Google-таблицы соавтора, только чтение. Источник правды — оригиналы; эти файлы
нужны, чтобы агенты читали таблицы без доступа к Google. Для игры используются снимки и
наборы данных в [packages/canonical-data](../packages/canonical-data/) (ADR 0005), а не эти
файлы.

## Обновление

Когда соавтор меняет таблицу: скачать её из Google («Файл → Скачать → .xlsx»), вырезать
картинки, заменить файл здесь и обновить дату и таблицу выше. Если изменились листы, которые
снимает `packages/canonical-data`, — сделать новый снимок по ADR 0005.
