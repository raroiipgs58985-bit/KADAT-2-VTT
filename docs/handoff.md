# Handoff — где проект сейчас

Этот файл читают в начале каждого чата (Claude, ChatGPT, Codex) и обновляют в
конце каждого этапа. Правила — в разделе «Этапы» [AGENTS.md](../AGENTS.md).

Последнее обновление: 2026-11-27, по состоянию ветки `claude/eager-gauss-pf5ww0`
на коммите `12dcd0a` (плюс коммит `ff21d5a` с этим файлом и шаблоном ТЗ).

## Текущее состояние

- **Rules Engine** (`packages/rules-engine`): Infantry Rules Kernel
  (Phase 2.2A–2.2D) сверен с каноном ([СВЕРКА-ЯДРА.md](../СВЕРКА-ЯДРА.md),
  [ОТЧЁТ-ШАГА-1.md](../ОТЧЁТ-ШАГА-1.md)) и дополнен решениями автора 1–173:
  характеристики, проверки, инициатива, ОД, движение, дальний и ближний бой,
  реакции, захват, броня и урон, ранения, кровь, подавление, свойства оружия,
  таланты, гранаты, укрытия. 834 теста.
- **Клиент** (`apps/client`, React + Vite), локальный, без сервера:
  - карта до 200 × 200: редактор, подложка с калибровкой, декорации, стены,
    двери (в т. ч. окна), препятствия-укрытия, зоны трудного ландшафта, файл
    `*.kadat-map.json`;
  - бой любого состава из библиотеки персонажей: инициатива, ломаный маршрут,
    атаки любым оружием «Арсенала», реакции, урон и ранения через ядро,
    вопросы ведущему вместо остановок, журнал, replay;
  - предварительный порог атаки d100 через ядро ([ADR 0007](adr/0007-attack-preview.md));
  - desktop-интерфейс «Имперский тактический когитатор» / «Планшет» на
    UI Kit v0.2 ([ui-redesign.md](ui-redesign.md)); телефон — прежняя вёрстка;
  - демо-локация «Демо: аванпост» (меню «Сценарии», адрес `#demo`).
  - 342 теста клиента, браузерный smoke — 174 проверки.
- **Генератор персонажей** перенесён в `apps/generator` без таро
  ([ADR 0006](adr/0006-character-generator-in-monorepo.md)), передаёт персонажа
  в библиотеку VTT. Сверка правил создания с таблицами не сделана.
- **Не подключено:** сервер боя, realtime, база данных, аутентификация, CI.

## Решения

Канон и архитектура — в [rules-sources.md](rules-sources.md),
[architecture.md](architecture.md), [adr/](adr/). Решения по правилам 1–173 —
в [ВОПРОСЫ-ПО-ПРАВИЛАМ.md](../ВОПРОСЫ-ПО-ПРАВИЛАМ.md). Здесь — решения,
важные для следующих этапов:

- VTT только для боя; механики вне боя не делаем (22.11.2026).
- Порядок шагов плана утверждён 22.11.2026 ([ПЛАН-РАЗРАБОТКИ.md](../ПЛАН-РАЗРАБОТКИ.md)).
- Своя VTT, чужой код — только под разрешительной лицензией
  ([ADR 0004](adr/0004-own-vtt-and-code-reuse.md)).
- Ассеты с ограничительными лицензиями (GameReadyPixels, StationSupply, Nexa)
  хранятся вне публичного репозитория; в открытый GitHub — только при
  подтверждении, что лицензия это разрешает.
- Google-таблицы KADAT — только чтение.
- Визуальный концепт «Планшет» выбран; KADAT 2 UI Kit v0.1 утверждён как
  библиотека; графика — отдельные компоненты (9-slice, WebP), без монолитных
  растров.
- Предварительный порог атаки — только через ядро, без копии формул, без
  бросков и побочных эффектов; вместо числа — причина
  ([ADR 0007](adr/0007-attack-preview.md)).
- Desktop первым; мобильная вёрстка «Планшет» — после утверждения desktop.
- ОБ укрытий в демо-локации — тестовые значения (ящики и мешки 6, стены 8,
  окно 5), не канон (27.11.2026).
- Ошибки ядра показываются по-русски, исходное сообщение ядра сохраняется в
  журнале (вид ГМа).

  принята ли как окончательная, не решено.

- По правилам: линия видимости и атака сквозь преграды (вопросы 35–36),
  тест взлома запертой двери — см. [ВОПРОСЫ-ПО-ПРАВИЛАМ.md](../ВОПРОСЫ-ПО-ПРАВИЛАМ.md)
  и [tactical-scene-client.md](tactical-scene-client.md#открытые-вопросы-автору).
