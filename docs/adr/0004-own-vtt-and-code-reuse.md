# 0004 — Own VTT for KADAT; reuse of external code under compatible licences

## Status

Accepted — решение пользователя (ноябрь 2026).

## Context

После этапа 3 ТЗ тактической карты рассматривались альтернативы собственной VTT:
платная платформа (Foundry VTT), обратная разработка закрытых платформ и VTT с
открытым кодом (PlanarAlly — MIT; MapTool, CozyVTT — AGPLv3; Owlbear Rodeo
Legacy — только некоммерческое использование). Проба PlanarAlly в облаке
показала: игра нескольких участников, обзор и туман есть; интерфейс под телефон
не адаптирован; модам недоступен перехват перемещения, поэтому проверка хода по
правилам KADAT потребовала бы переделки чужой платформы.

## Decision

- KADAT 2 развивается как собственная VTT под правила и механики KADAT.
  Переход на чужую платформу не рассматривается.
- Чужой код (других VTT, библиотек, прежних проектов пользователя) разрешено
  встраивать, если лицензия это допускает:
  - MIT, BSD, Apache-2.0, ISC и подобные разрешительные лицензии — да, с
    сохранением уведомления об авторстве и лицензии в `THIRD_PARTY_NOTICES.md`
    рядом с указанием, какой файл или фрагмент заимствован;
  - GPL/AGPL — только после отдельного решения пользователя, так как это
    обязывает распространять весь проект под той же лицензией;
  - код без лицензии, закрытый, «только некоммерческий», а также полученный
    обратной разработкой с нарушением лицензии — не встраивается.
- Заимствованный код не определяет механику: правила KADAT берутся только из
  канонических источников и решений автора.

## Consequences

- Решения других проектов (например, обзор и туман PlanarAlly) можно переносить
  напрямую, а не только как идеи, при соблюдении уведомлений.
- Каждое встраивание фиксируется в `THIRD_PARTY_NOTICES.md` в том же изменении.
- Разделение Rules Engine / Client / Server сохраняется; встроенный код не должен
  делать ядро правил зависимым от интерфейса, сети или хранения.
