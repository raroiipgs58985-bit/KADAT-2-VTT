# ADR 0006: генератор персонажей в монорепо и связь с VTT

Дата: 23.11.2026. Статус: принято (решение автора о шаге 5: перенос генератора без
модуля таро; запрос автора встроить генератор так, чтобы созданный персонаж сразу
попадал в бой).

## Контекст

У автора есть готовый генератор `Kadat-Character-Generator` (статическое приложение
на JS без сборки, четыре конструктора: персонаж, полк, ксенос, серво-броня, 507
эталонов старого движка в тестах). VTT держит свой боевой лист персонажа
(`CharacterDocument`). Переписывать генератор целиком на TypeScript — долго и
рискованно для уже проверенных расчётов.

## Решение

- Генератор перенесён в `apps/generator` как есть, без `tarot-prototype/`, со своими
  тестами (`pnpm --filter @kadat/generator test`) и своими настройками Prettier
  (корневые Prettier и ESLint его не трогают).
- VTT раздаёт генератор по адресу `/generator/` (плагин в `apps/client/vite.config.ts`;
  при сборке файлы генератора копируются в `dist/generator`). Один адрес — общее
  хранилище браузера.
- Кнопка генератора «В KADAT VTT» записывает досье как есть в
  `localStorage["kadat.generator-outbox.v1"]` (`src/services/vtt-export.js`).
- VTT переводит досье в боевой лист (`apps/client/src/game/generator-import.ts`):
  характеристики и Сверх (из черт «СверхСЛ (+2)»), раны, Размер, навыки, таланты;
  СКР = бЛВ + Размер, 0,5 м при нуле и меньше («Общая механика» A25); снаряжение
  с точным совпадением названия становится оружием или бронёй Арсенала, остальное
  остаётся в заметках.

## Последствия

- Правила создания в генераторе пока прежние. Сверка с таблицами («Профили
  персонажей», затем «Механика к100») и исправления — отдельными шагами с тестами.
- ОБ брони после переноса задаёт ведущий кнопкой «Взять ОБ из брони».
- Обмен идёт только в одном браузере на одном адресе; на другое устройство персонажа
  переносят файлом.
