# Оформление «Имперский тактический когитатор»: сопоставление и план

Статус: художественное направление **предварительно одобрено** пользователем
(макеты: холст «KADAT 2 — Имперский тактический когитатор», 7 листов). Этот
документ сопоставляет макеты с текущим интерфейсом `apps/client` и делит работу
на оформление и изменения UX. Реализация — только по этапам ниже, каждый этап
сохраняет работоспособность (проверки, тесты, браузерный smoke).

## Утверждённые основы

- Палитра: фон `#0B1011`, карта `#101A1B`, панели `#162022`, приподнятые
  `#202D2E`, границы `#354746`, текст `#C9D2C7`, второстепенный текст
  `#9BAEA4` (светлее исходного `#80928A` — доработка 2), терминальный
  зелёный `#829C78`, янтарь `#C9A66B`, опасность `#BF625B`, союзники `#75A6B4`.
  Цвет обозначает состояние, не украшение.
- Шрифты: IBM Plex Sans Condensed (интерфейс), IBM Plex Mono (числа, броски,
  координаты, телеметрия). Оба с кириллицей.
- Строгие рамки 1 px, прямые углы; умеренная имперская стилизация: таблички
  со скосом и номером, уголки, «+++» в заголовках телеметрии.
- Приоритет карты; структура панели атаки; структурированная телеметрия;
  компактный мобильный HUD.

## Границы

Не меняются: Combat Core (`packages/rules-engine`), канонические данные и
правила, формулы, характеристики, формат replay и файлов. Числа в макетах —
пример раскладки, не игровые данные. Все существующие функции сохраняются.

## Этапы реализации

1. **Токены и шрифты (А).** Палитра, шрифты, панели, кнопки, плашки по всему
   приложению. Поведение не меняется.
2. **Карта и токены (А + Б).** Цвета карты, подписи, восьмиугольные рамки,
   корпуса для больших токенов.
3. **Компоновка ПК (Б + В).** Панель команд над картой; сворачиваемые и
   изменяемые панели; шапка.
4. **Телефон (В).** Новая мобильная компоновка.
5. **Журнал и атака (В).** Структурированная телеметрия; расчёт порога — после
   согласования.
6. **Досье (В).** Просмотр персонажа во весь центр.
7. **Портреты (Г).** После решения о поле изображения.

На каждом этапе: `format:check`, `lint`, `typecheck`, `test`, браузерный smoke
(ПК и 390 px), публикация страницы для телефона.

## UI Kit v0.2 в desktop (26.11.2026)

Утверждено пользователем: KADAT 2 UI Kit v0.1 как основа, затем частичное
внедрение в рабочий клиент, сначала desktop. Телефон — после утверждения desktop.

Сделано:

- **Ресурсы** — `apps/client/src/ui/kit/assets`: отдельные компоненты набора
  (WebP ×3, прозрачный фон). Панели, рамки, клавиши, поля, прорезь шкалы —
  9-slice через `border-image`. Газоразрядный индикатор и лампы — картинки,
  цифры живые. Монолитной картинки интерфейса нет.
- **v0.2** — недостающие для рабочего клиента компоненты: компактная клавиша
  `key-sm` (6 состояний), поле `field-inset`, флажок `check-on/off`, прорезь
  шкалы `bar-slot`.
- **Стили** — `ui/kit/kit.css` поверх `styles.css`. Оболочка (панели, клавиши,
  поля, рамка карты, журнал) действует от 761 px. Компоненты (индикатор, лампы,
  блок порога) работают на любой ширине.
- **Разметка**:
  - `TurnBar`: раунд на газоразрядном индикаторе, ОД — лампами (класс `pip`
    сохранён), реакция — зелёной лампой, «Передать ход» — клавиша
    подтверждения;
  - `AttackPanel`: блок «ПОРОГ d100» (ADR 0007), «Атаковать» — крупная клавиша;
  - `App`: команда атаки собирается одной функцией для кнопки и предпросмотра.
- **Исправление**: у бойца без оружия форма атаки по умолчанию брала пустое
  оружие, и атака кулаками падала с «Оружие не принадлежит атакующему». Теперь
  по умолчанию берутся кулаки — то, что панель уже показывала.

Не менялись: правила, Rules Engine (кроме ADR 0007), данные, replay, поведение
компонентов. Проверки: `format:check`, `lint`, `typecheck`, `test` (ядро 834,
клиент 332), браузерный smoke — 174 проверки, без ошибок браузера.

## Desktop, этап 2: компоновка «Планшет» (26.11.2026)

Этап 1 принят как технический checkpoint. Этап 2 — только desktop (от 761 px);
телефонная вёрстка не менялась.

- **Компоновка** по концепту «Планшет»: экран на всю высоту окна, карта
  занимает всю центральную колонку. Слева — оливковый модуль «Ход и боец»,
  справа — синий модуль «Действия и журнал» (асимметричные фигурные панели
  набора, `panel-olive-cut` / `panel-navy-cut`). Внутренние секции плоские —
  одна металлическая рамка на модуль вместо рамки на каждую секцию.
- **Сворачиваемые модули**: кнопка `dock-toggle` (`aria-expanded`), свёрнутый
  модуль — узкая планка с вертикальной подписью. Состояние в `localStorage`
  (`kadat.ui.docks`), только удобство одного зрителя.
- **Блок атаки** — сетка в две колонки (цель/оружие, тип/приём), пояснения
  на всю ширину; нулевые модификаторы в блоке порога не показываются. При
  1920×1080 атака и последние записи журнала видны одновременно; при 1366×768
  панель действий прокручивается внутри, журнал остаётся на экране.
- **Карта**: переключатель «Фактуры» (`kadat.ui.mapTextures`) — стальной пол,
  фактурные стены, сигнальные полосы закрытой двери, ящики-препятствия.
  Выключен — прежняя чистая сетка; пользовательские подложки и разметка пола
  работают в обоих режимах. Плитки — SVG-паттерны в метрах карты, не растр
  целой карты.
- **Выпадающие списки** — явная янтарная стрелка.
- **Ошибки**: `game/errors.ts` переводит сообщения ядра на русский; исходное
  сообщение ядра сохраняется в данных журнала (`diagnostic`) и показывается
  в виде ГМа как «Ядро: …». Неизвестное английское сообщение — общий русский
  текст плюс исходник.
- **Проверка предпросмотра атаки** (ADR 0007), `attack-preview-safety.test.ts`:
  перехватчики восстанавливаются после исключения в ядре и в клиенте;
  состояние боя не меняется; следующая реальная атака совпадает с атакой без
  предпросмотров; `Math.random` и `crypto.getRandomValues` не вызываются;
  повторные вызовы дают тот же результат, что на свежем бою. Изменения кода
  предпросмотра не понадобились.

Не менялись: правила, Rules Engine, расчёт движения и атаки, данные, replay,
мобильная вёрстка. Проверки: `format:check`, `lint`, `typecheck`, `test`
(ядро 834, клиент 341, данные 18, сервер 1), браузерный smoke — 174 проверки.
