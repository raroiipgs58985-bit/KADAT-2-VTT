# Предварительная архитектура KADAT 2

KADAT 2 — браузерная VTT-платформа с собственной системой правил. Ниже
зафиксировано утверждённое пользователем направление Phase 0.1. Отдельные
технические детали могут изменяться по мере уточнения требований; такие
решения должны быть документированы. Предложения и кандидаты не считаются
утверждёнными решениями.

## Направление разработки

| Область | Направление | Статус |
| --- | --- | --- |
| Frontend | React + TypeScript + Vite | Утверждённое направление Phase 0.1 |
| Backend | Node.js LTS + Fastify | Утверждённое направление Phase 0.1 |
| Realtime | WebSocket layer | Кандидат; библиотека и протокол сообщений не выбраны |
| Core | Independent Rules Engine | Утверждён принцип независимого ядра; реализации нет |
| Repository | pnpm workspace | Запланирован; пока не настроен |

## Границы системы

- **Client** отвечает за интерфейс и взаимодействие пользователя с платформой.
  Интерфейс не определяет игровые правила.
- **Server** отвечает за серверные операции и будущие многопользовательские
  сессии. Серверный framework не должен определять механику KADAT.
- **Rules Engine** в дальнейшем реализует только утверждённые правила KADAT.
  Ядро должно быть независимо от интерфейса, React, Fastify и транспорта
  сообщений. Client и Server могут обращаться к ядру через явно определённые
  границы; ядро не должно зависеть от этих приложений.

Источники механики и порядок разрешения конфликтов описаны в
[rules-sources.md](rules-sources.md). Замена механики правилами других систем
не допускается.

## Состояние Phase 0.2

На этом этапе репозиторий содержит документацию и базовые конфигурационные
файлы. Приложения Client и Server, Rules Engine и игровые подсистемы пока
не реализуются. Зависимости, `package.json`, настройка workspace, тесты и CI
в объём Phase 0.2 не входят.

Версии инструментов, внутренняя структура workspace и конкретная реализация
realtime будут уточняться отдельными решениями. Архитектурные решения
фиксируются в [ADR](adr/README.md); отдельных ADR на этом этапе нет.
