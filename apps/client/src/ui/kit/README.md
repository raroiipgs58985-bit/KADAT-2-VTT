# KADAT 2 UI Kit v0.2 (клиент)

Графические компоненты оформления «Имперский тактический когитатор».

- `assets/` — отдельные ресурсы (WebP, ×3, прозрачный фон, контактная тень).
  Источники и лицензии — в `THIRD_PARTY_NOTICES.md`.
- `kit.css` — классы и правила: 9-slice через `border-image`. `border-image-width`
  больше `border-width`, поэтому рамка рисуется поверх, а отступы содержимого
  остаются прежними. Оболочка действует на desktop (≥ 761 px).
- `Kit.tsx` — `Nixie` (газоразрядный индикатор), `Lamp` (лампа),
  `AttackReadout` (блок «ПОРОГ d100», ADR 0007).

Правила: текст, цифры и шкалы — живые; картинки не зеркалить (свет общий,
сверху-слева); минимальный размер 9-slice-элемента — два «слайса» по оси.
Полный набор (67 компонентов, манифест, React-обёртки) — пакет `kadat-ui-kit`
вне репозитория.
